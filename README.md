# 🚀 Featured Projects

### [phishingtool](https://github.com/vuralogur/phishingtool) — Phishing Email Detection Engine

A command-line and GUI analyzer that inspects `.eml`, `.msg`, and raw email files for phishing indicators, producing an **explainable risk score** where every point is tied to a named rule and its evidence.

- **Analysis:** Fully static — attachments are never executed, links are never opened
- **Scoring:** Transparent rule-based weighting with `low` / `medium` / `high` / `critical` verdicts
- **Threat Intel:** MITRE ATT&CK technique mapping per triggered indicator
- **IOC Extraction:** URLs, domains, IPs, email addresses, and file hashes
- **Header Forensics:** `Received` hop analysis reconstructing the mail transit path
- **Online Checks:** Optional SPF, DKIM, DMARC, WHOIS, and reputation API verification
- **Deep Inspection:** `.msg` parsing via a native OLE2/CFB implementation, QR code detection in attachments and inline images, macro detection, and PDF active-content scanning
- **Accuracy:** Batch processing with precision / recall / F1 metrics
- **Output:** HTML reports plus a desktop GUI (CustomTkinter)
- **Stack:** Python 3.11+ — core runs on the standard library alone
